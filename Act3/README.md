# Act3 - Búsqueda local

Optimización de una función real de dos variables con varios mínimos locales. Se comparan ascenso de colina (Hill Climbing) y recocido simulado (Simulated Annealing) con las mismas condiciones iniciales, 30 semillas y parámetros declarados. `act3_optimizacion.py` genera la gráfica de convergencia y resultados JSON.
