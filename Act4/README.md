# Act4 - Búsqueda ciega BFS y DFS

`act4_laberinto.py` resuelve un laberinto didáctico con búsqueda en anchura y profundidad. Exporta el plano original, las rutas, la representación del grafo, métricas de tiempo y nodos expandidos, y resultados JSON. El orden de vecinos se fija para facilitar reproducibilidad.
